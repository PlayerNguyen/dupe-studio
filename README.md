# Dupe Studio

Dupe Studio is a cross-platform desktop application built with [Tauri](https://tauri.app),
React, and TypeScript for inspecting and querying multiple database management systems (DBMS)
from a single interface.

## Features

- Connect to several DBMS backends from one place.
- Browse schemas, tables, and records.
- Run ad-hoc queries and inspect the results.

## Development

```sh
bun install
bun run tauri dev
```

See [AGENTS.md](./AGENTS.md) for the full command list and verification steps.
